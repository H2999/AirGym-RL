# 整机重心怎么测

2026-11-08 用户更正：整机装配后称重205g；没有新增部件，原160g来自不准确估计/分别测量。重心主观偏高，尚无准确坐标。不能把45g当作新装在顶部的点质量，也不能由总质量直接推算惯量。

## 建议先用悬挂法

器材：细线、可靠支架、手机、尺子、机身标记。飞机保持实际飞行装配和电池安装位置，断开电池供电。若拆卸零件，记录拆卸质量和位置，结果不能直接当作完整205g飞机的重心。悬挂点选择承力机架，不能系桨叶、导线或相机。

1. 指定基准：以下层机架板的上表面为Z=0，Z向上；选择一个可在CAD/实物识别的板中心作XY原点，X向前、Y向左。记录实际用的是哪块板和哪个面。
2. 在同一机身侧面贴至少3个不共线的可见标记，放置同平面的已知尺寸参照。选侧向观察位置，尽量避免透视与出平面旋转。
3. 从机架位置A自由悬挂，等静止。拍清机架标记、悬挂点及绳的竖直方向；可在同一悬挂点另外吊铅垂线以便看清方向。重心在通过悬挂点的铅垂线上。
4. 换到相隔较远的位置B悬挂，再拍。两次应产生明显不同的机体姿态，否则交点误差会很大。
5. 根据机身标记把两次照片对齐到同一机体姿态，再在各照片中延长相应的铅垂线。交点给出这个视图中的重心投影，不能直接叠加未对齐的两张照片。
6. 将重心投影到下板基准，换算沿机体Z轴的高度h（mm），不是飞机悬挂时相对地面的竖直高度。换C点复测，交点的分散范围反映部分测量误差。

侧视得到前后位置与高度；再从正面重复可估计左右位置并交叉检查高度。单机位且有明显出平面转动时，二维叠图不可靠，需要多视图标定/三维摄影测量。不要据普通照片承诺毫米级精度。

原理与工程测量参考：[NASA 重心测定](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/center-of-gravity/)、[NASA 铅垂线摄影测量实例](https://www.nasa.gov/centers-and-facilities/nesc/center-of-gravity-determination-using-photogrammetry/)。

## 如果使用SW

逐件测得电池、主控、飞控、电调、相机等质量，利用已存在的装配位置计算重心；机架指定合理材料。可以使用组件质量覆盖，但不要只把整机总质量覆盖成205g，就认为重心/惯量也准确了。[SolidWorks 质量属性覆盖](https://help.solidworks.com/2026/english/SolidWorks/sldworks/HIDD_ASSIGNMASSPROP_TEXT_DLG.htm)

建议先用悬挂结果检查SW重心，随后保留完整惯量张量、坐标系和单位。悬挂法确定重心，不直接给出转动惯量。

## 给工程的数据

- 整机质量205g；是否包含电池/桨叶等实际飞行部件。
- 基准板/表面照片，带比例尺的侧面及正面悬挂照片，各至少两种悬挂姿态。
- 若自行读数：X、Y、Z坐标（mm）与重复测量范围；没有可靠读数保留null。
- 若有：实际部件质量和SW质量属性输出。

# 自主姿态恢复版本验证记录

历史记录：本页是旧版 X152b 的 v2 检查。当前 160g CAD 机型的 v3 检查见 [user_aircraft.md](user_aircraft.md)，下列旧权重不能用于新机型。

验证日期：2026-11-02。任务 schema：`armor_impact_attitude_v2`，30 维观测。

当前结果只证明环境与训练链路可以运行，**尚未训练出满足 5 m/s 撞击后 2 秒内稳定姿态的策略**。旧版 33 维模型的成功率不适用于本版本。

## 环境检查

在本机 `airgym_dev` 环境、RTX 4060 Laptop GPU 上执行：

```bash
python tools/check_armor_impact.py --ctl_mode rate --num_envs 4 --headless --seed 42
python tools/check_armor_impact.py --ctl_mode rate --num_envs 4 --headless --seed 42 --zero-restitution
```

两组检查均通过，包括：基地和前哨站装甲板实际接触、非接触靠近不计命中、撞速资格判定、完整 2 秒恢复窗口、触地失败、不同位置和带水平速度时的姿态稳定判定、持续旋转时不能成功，以及部分环境重置和控制器积分状态独立重置。

恢复系数固定为 0 时，5 m/s 法向入射后的法向速度接近 0，两个装甲板均记录到接触力。该结果确认任务不依赖预设反弹；接触产生的动量变化由求解器处理。接触力采样值不是实机载荷或结构损伤预测。

从随机参数运行 3 个 PPO epoch，训练数值有限并成功保存模型：

```text
runs/armor_attitude_smoke_02-17-45-06/nn/last_armor_attitude_smoke_ep_3_rew__-95.51539_.pth
SHA256: 3f3919242a49e29513f46a743e30b46e4409ebdcf9ffca5f6c91cccfe9b9e0eb
```

随后以 seed 62、4 个环境、4 个完整回合加载该权重进行评估，保存/加载/终止/报告流程正常。结果为命中率 0%、成功率 0%、失败坠机率 100%。这只是短程链路检查，模型没有收敛，不应作为演示或部署策略。
